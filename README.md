# 寶隆線索與案件跟進 Demo

可操作的繁體中文展示系統，紅黑視覺，資料與人名均為虛構。包含營運總覽、線索收件與派店、案件看板、跑案紀錄、洽談對象、止血成效、建案總覽與營運報表。

## 執行

雙擊 `start-demo.command`，或在本目錄執行 `python3 serve.py --open`。不需要 npm 安裝；所有圖示、圖表、程式及樣式均為本機資產。

## 展示路線

1. 營運總覽 → 點開逾期線索 → 派店、記錄聯絡、轉為案件。
2. 案件看板 → 開案件 → 新增跑案紀錄、照片、下一步 → 變更階段。
3. 洽談對象 → 尚未立案的機會 → 新增拜訪或轉為案件，保留歷史。
4. 建案總覽 → 戶別進度 → 一次新增多戶拜訪。
5. 止血成效 → 查看風險與介入紀錄 → 已成交案件覆核留單。
6. 營運報表 → 切換門市與期間、匯出 CSV。

操作保存在目前瀏覽器，重新整理仍可接續；設定內可還原展示資料。更換瀏覽器不會共享操作。

## 架構與展示假設

- `dist/data.js`：模擬資料與基礎字典。
- `dist/app.js`：狀態保存、共用計算、畫面、表單及互動。
- `dist/styles.css`：紅黑配色、柔和層次與 RWD。
- `dist/index.html`：無建置步驟的靜態入口。
- `serve.py` / `start-demo.command`：本機啟動。
- 展示採 4 小時首次聯絡期限；不是寶隆已裁定的業務規則。
- 角色只切換模擬視角。資料不經伺服器保存，不適合輸入真實個資。
- 官網、LINE、出圖、報價、簽認事件皆為展示資料；語音按鈕填入可編輯的模擬轉錄文字，介面明確標示。
- 模擬報表由同一份狀態計算；止血成果只計經覆核且案件仍成交的機會，建案金額每案件計一次。
- 本版不含正式登入、後端權限、外部介接、GPS、考勤、行程排程或對屋主發訊。

## 設計

主色朱紅 `#F33D35`、黑色 `#141414`；內容底 `#F6F7F9`、白色 `#FFFFFF`，輔助紫 `#8C65E8`、綠 `#1D9469`。字體使用系統繁體中文無襯線，數字以 tabular-nums 對齊。黑色側欄與亮紅重點區形成品牌辨識，內容採精簡表格、操作抽屜、彩色狀態及清楚的下一步；不把所有內容做成同一種卡片。手機以折疊導覽與直式案件卡呈現。
